Terminbuchung (Calendly)

Auf der Kontaktseite ist ein Buchungs-Widget von Calendly eingebunden (Calendly LLC, USA). Beim Laden des Widgets werden Daten, unter anderem Ihre IP-Adresse und Nutzungsdaten, an Calendly übermittelt. Wenn Sie einen Termin buchen, verarbeitet Calendly die dabei angegebenen Daten (Name, E-Mail, Terminwunsch). Es gilt die Datenschutzerklärung von Calendly.

Kontaktformular

Das Kontaktformular sendet keine Daten an einen Server. Es öffnet lediglich Ihr lokales E-Mail-Programm mit einer vorausgefüllten Nachricht. Erst mit dem Absenden dieser E-Mail übermitteln Sie Ihre Angaben an mich; ich verarbeite sie ausschliesslich zur Bearbeitung Ihrer Anfrage.
